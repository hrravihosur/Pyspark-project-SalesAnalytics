# 20-Day Learning Roadmap

| Day | Focus | Core learning |
|---|---|---|
| 01 | Python Fundamentals | Types, collections, conditions, loops, functions |
| 02 | Python Advanced | Lambda and functional-style expressions |
| 03 | PySpark Fundamentals | SparkSession and DataFrames |
| 04 | Spark Architecture | Jobs, stages, tasks, executors, shuffle |
| 05 | DataFrames | DataFrame structure and expressions |
| 06 | Schema & I/O | Schemas, reading and writing data |
| 07 | Transformations | Select, filter, withColumn, union, deduplication, ordering |
| 08 | PySpark Functions | Column expressions, strings, conditional logic and regex |
| 09 | Dates & Nulls | Date functions and null handling |
| 10 | Aggregations | groupBy, pivot, rollup and cube |
| 11 | Joins | Inner, outer, semi and anti joins |
| 12 | Windows | row_number, dense_rank, running totals and frames |
| 13 | Spark SQL | Temporary views and SQL-based transformations |
| 14 | Lazy Evaluation | Transformations vs actions and execution planning |
| 15 | DAG & Execution | Jobs, stages, tasks and executor behavior |
| 16 | Partitioning | Partition strategy, parallelism and shuffle |
| 17 | Optimization | Predicate pushdown, pruning, AQE, broadcast, skew, cache and small files |
| 18 | Read / Write & Delta | Storage formats and Delta fundamentals |
| 19 | Delta / CDC | MERGE, CDC, deduplication and idempotency |
| 20 | End-to-End Project | Azure-style Customer Sales Analytics pipeline |

## Learning pattern

**Concept → Hands-on Practice → Real-world Scenario → Production Consideration**

The first 19 days build the individual skills. Day 20 combines them into one coherent data engineering solution.
